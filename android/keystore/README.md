# مفتاح التوقيع الثابت / Stable app signing key

`mahdi.p12` هو **مفتاح التوقيع الموحّد** لكل بناءات APK في هذا المشروع
(سير عمل البناء الفرعي وسير عمل الإصدارات على حد سواء).

## لماذا مفتاح ثابت؟
سابقاً كان كل بناء `assembleDebug` على GitHub Actions يُوقَّع بمفتاح تصحيح
مؤقت يُولَّد على جهاز البناء نفسه، فيختلف المفتاح من إصدار لآخر. وعند محاولة
تثبيت إصدار جديد فوق إصدار قائم كان أندرويد يرفض التحديث برسالة
**"App not installed"** لاختلاف بصمة التوقيع. توقيع كل الإصدارات بهذا المفتاح
يجعل التحديث فوق النسخة القديمة يعمل دائماً طالما versionCode أعلى.

## ملاحظات أمنية
- هذا المفتاح مخصص لتوزيع التحميل الجانبي (sideload) عبر GitHub Releases فقط.
- إذا نُشر التطبيق مستقبلاً على متجر Play يجب توليد مفتاح رفع جديد تماماً وعدم
  استخدام هذا المفتاح له.
- إعادة توليد هذا المفتاح أو استبداله تعيد المشكلة: سيضطر المستخدمون لإلغاء
  تثبيت التطبيق مرة واحدة قبل تثبيت أول إصدار موقّع بالمفتاح الجديد.
- بصمة المفتاح تُطبع في سجل البناء عبر خطوة `Verify APK signing identity`
  للتأكد من ثباتها بين الإصدارات.
